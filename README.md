# A Little Moonlit Garden

An interactive, local-first gift for a long-distance friend, with a lily-of-the-valley garden, a personal note, and a tiny plushie hunt.

## Run Locally

Open `index.html` in a browser, or start a local server from this folder:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Personalize

Edit the messages and letter in the `CONFIG` object at the top of `script.js`. The recipient's name is intentionally left open until you choose what to call her.

The active visual theme is in `friendship.css`. The page uses original CSS illustrations and does not depend on GitHub or a deployment service.
